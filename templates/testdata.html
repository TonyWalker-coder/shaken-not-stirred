About This Page

This page has been designed as a testing aid. It does not restrict, alter, or influence the assessment process in any way. Everything here is optional.

You are completely free to bypass this page and test the application manually, including breaking and restoring data through your own methods. These tools simply provide a safe, convenient way to explore the system without needing to access the operating system or database directly.

Feel free to use it — or ignore it — as you see fit. The choice is yours.

Local Deployment Only

This test must be performed on your local deployment. PythonAnywhere uses aggressive outbound (egressive) caching for static files, which prevents real-time break/fix testing on the live server.

Image Fallback Test

The cocktail images in this project have a built‑in fallback system. If an image cannot be found or is missing, the UI automatically displays a safe placeholder instead of breaking the layout.

These buttons provide a simple, safe test of that functionality by temporarily renaming the Bloody Mary image file.

Use Break Bloody Mary Image to simulate a missing image, and Fix Bloody Mary Image to restore it.

Database Reset & Restore

This tool allows you to completely wipe the cocktail database and restore it from a clean JSON file stored in static/testdata/cocktails.json.

It safely deletes all cocktails, ingredients, recipes, and history entries, then rebuilds them exactly as defined in the JSON file.

Working With the Admin Page

This section has been designed to work alongside the main admin page. When opened, Testdata loads in its own browser tab so you can switch freely between the two pages.

This makes it easy to cut, paste, compare, and test data without losing your place or interrupting your workflow.

Adding Test Cocktails

The following steps help you test cocktail creation in a controlled and repeatable way.

Add a cocktail named Fall Guy. If it already exists, delete it first.

  • History: Fall Guy was created to aid in the testing of Shaken Not Stirred.
  • Recipe: Fall Guy is made from all the things a good fall guy should have.

Add an ingredient named Tap Water before creating Fall Guy.

Next, add Testy. Fill in history/recipe with any text.

Finally, add Quickie using a new ingredient such as Mango Juice.

Delete a Cocktail

Any cocktail can be deleted. Ingredients are never deleted automatically.

Please delete Quickie before continuing.

History

The History modal shows all cocktails and whether they have history entries.

Testy may show either a red X or a scroll icon depending on your actions.

You may freely add, edit, or delete history entries.

Recipe

The Recipe modal works the same way as History.

Testy may show either a red X or an open book icon.

You may freely add, edit, or delete recipes.

Ingredients

Ingredients show whether they are used in any cocktail.

Used ingredients cannot be deleted.

Unused ingredients show a red X and may be deleted safely.

Customise Cocktail

This section allows you to change the ingredients used by any cocktail.

Select Fall Guy or Testy and adjust their ingredient lists freely.
