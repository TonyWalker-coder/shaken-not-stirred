About This Page

This page has been designed as a testing aid. It does not restrict, alter, or influence the assessment process in any way. Everything here is optional.

You are completely free to bypass this page and test the application manually, including breaking and restoring data through your own methods. These tools simply provide a safe, convenient way to explore the system without needing to access the operating system or database directly.

Feel free to use it — or ignore it — as you see fit. The choice is yours.

Image Fallback Test

The cocktail images in this project have a built‑in fallback system. If an image cannot be found or is missing, the UI automatically displays a safe placeholder instead of breaking the layout.

These buttons provide a simple, safe test of that functionality by temporarily renaming the Bloody Mary image file. This allows you to break and restore the image without needing to open the OS or touch the filesystem manually.

Use Break Bloody Mary Image to simulate a missing image, and Fix Bloody Mary Image to restore it. Both actions are safe and will quietly continue even if the file is already in the expected state.

Database Reset & Restore

This tool allows you to completely wipe the cocktail database and restore it from a clean JSON file stored in static/testdata/cocktails.json.

It safely deletes all cocktails, ingredients, recipes, and history entries, then rebuilds them exactly as defined in the JSON file.

This provides a fast, reliable way to reset the system for testing without needing to use the terminal or database tools.

Nothing here overrides or replaces the admin page — it simply provides additional convenience while you explore and test the system.

Adding Test Cocktails

The following steps are designed to help you test the cocktail creation process in a controlled and repeatable way. These instructions work alongside the admin page, allowing you to switch between tabs and copy or paste text as needed.

To begin, add a cocktail named Fall Guy. If the cocktail already exists, you will receive an error message — simply skip ahead to the Delete Cocktail section and remove it before continuing.

When adding Fall Guy, use the following suggested text:

  • History: Fall Guy was created to aid in the testing of Shaken Not Stirred. He got his name from being resilient — no matter what happens, he always gets back up.
  • Recipe: Fall Guy is made from all the things a good fall guy should have, then shaken not stirred.

Before creating the cocktail, add a new ingredient named Tap Water. Then select any combination of ingredients — including Tap Water — and click Create Cocktail.

Next, repeat the process by adding a second cocktail named Testy. You may optionally fill in the history and recipe fields with any random text. Select any ingredients for this cocktail.

Now add a third cocktail named Quickie. Again, you may fill in the history and recipe fields with any random text. For this test, create a new ingredient such as Mango Juice, and this time select any ingredients including Mango Juice before creating the cocktail.

These steps help demonstrate how the system handles new data, optional fields, ingredient selection, and validation behaviour.

Delete a Cocktail

The delete rule for this site is simple and intentionally destructive: any cocktail can be deleted. This includes its name, image URL, recipe, and history. Once confirmed, the deletion is permanent and the system provides only a single warning before completing the action.

Ingredients, however, are never deleted automatically. If you previously added an ingredient such as Mango Juice, it will remain in the system even after the cocktail that used it has been removed. This test demonstrates that ingredients are treated as independent entities, separate from the cocktails that reference them. This allows ingredients to be reused across multiple cocktails without risk of accidental loss.

Please delete the cocktail Quickie before continuing, as it was added specifically to demonstrate this behaviour.

Use this section to remove test cocktails such as Fall Guy or Testy before repeating creation tests or resetting the database.
